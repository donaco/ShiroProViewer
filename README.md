### このプロジェクトについて
御城プロジェクトRE 専用ブラウザです。
ブラウザ以外の機能はありません。

## 主な機能
* スクリーンショット
* ミュート
* ダークモード
* 最前面に表示
* 画面の拡大縮小

## 設定とスクリーンショットの保存
* 設定はアプリ内の `Data\settings.json` に保存し、更新時に前回の設定を `settings.json.bak` に残します。
* 設定ファイルが破損している場合や保存先が不正な場合は、通知してバックアップから復旧します。バックアップも読み込めない場合は、通知して初期設定で起動します。
* 復旧後の最初の保存では、既存のバックアップを上書きしません。
* スクリーンショットはページの読み込み完了後に撮影できます。ゲーム内の追加読み込みが完了したことを保証するものではありません。
* 画像は撮影と書き込みが成功してから PNG ファイルとして確定します。通常の失敗時は一時ファイルを削除し、削除できない場合は通知します。
